# Image sample attribution

`sample_data/` contains 27 real waste images taken from the resized **TrashNet** dataset by Gary Thung and Mindy Yang. The images are included only as a small runnable sample for this educational project.

Original dataset repository: https://github.com/garythung/trashnet

Original report: *Classification of Trash for Recyclability Status*, Stanford CS229, 2016.

The three sample labels are mapped for this course project as follows:

- `cardboard` -> `biodegradable`
- `glass` -> `recyclable`
- `trash` -> `non_recyclable`

For the actual experiment, use `download_dataset.py` to obtain and prepare the full source dataset. Keep this attribution in any report or presentation based on these images.
